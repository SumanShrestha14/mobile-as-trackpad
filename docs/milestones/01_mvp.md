# MVP Milestone

## Goal
Deliver a minimal working trackpad experience over the local network.

## Tasks
- Build the mobile trackpad surface and connection screen.
- Implement motion capture and basic gesture classification.
- Define and serialize the initial message protocol.
- Build a Python server that accepts a client session.
- Map MOVE, TAP, DOWN, UP, and SCROLL events to desktop actions.
- Add heartbeat and reconnect behavior.

## Done when
- A phone can move the desktop cursor reliably.
- Tap, drag, and scroll work end to end.
- The session reconnects after a temporary network drop.
