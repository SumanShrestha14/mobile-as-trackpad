# Advanced Milestone

## Goal
Expand the system beyond the basic trackpad use case.

## Tasks
- Add keyboard shortcuts and modifier events.
- Add LAN discovery.
- Support multiple paired mobile devices.
- Explore Bluetooth as an alternate transport.
- Prepare desktop OS adapters for more platforms.

## Done when
- The protocol supports more than pointer movement.
- The transport and OS layers remain decoupled.
- New backends can be added without changing the gesture model.
