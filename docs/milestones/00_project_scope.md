# Project Scope

This file defines the implementation boundaries for the Phone-as-Trackpad project.

## Included
- Flutter mobile client
- Python desktop server
- WiFi transport over TCP sockets or WebSockets
- Gesture processing, protocol design, and OS input control

## Excluded for now
- Full implementation code
- Cloud sync
- Remote desktop video streaming
- Non-local network access

## Deliverables
- Mobile and server skeletons
- Shared protocol contract
- Initial connection and gesture milestones
- Security and performance baseline
